6. Problem found and fixed during testing

Rare program crash inside the Access Database Engine. Now and then the test process ended without an error message. A crash dump showed the cause: the Access Database Engine unloads when the last connection to the database closes, and loading it again occasionally fails.

Fix: the application now keeps one database connection open from start to exit, on its own thread. It is closed only while a backup is restored. This also protects the installed program when it is left open and idle for a long time.

Result: three full runs passed afterwards with no crash.

7. Notes for go-live

  • Gmail: email sending was tested with a test mail server. Real delivery needs the 16 letter Gmail app password, entered once in Email Settings on the client PC. Then use Send Test Email (TC-105).
  • Windows SmartScreen may warn on the first install because the installer is not code signed. Choose More info, then Run anyway.
  • Data: keep the daily automatic backup on, and set the second backup folder to a USB drive or cloud folder.
  • Future updates: if a later version changes the database layout, it must include an upgrade step for databases that already hold data. Please take Backup Now before installing any update.
